# EnergyScanAnalyzer（配布用）

分光器のエネルギースキャンデータ（athena 形式の列データ）を読み込み、ダーク差し引き・I0 による規格化・
ピークのフィット（Gauss・Lorentz・Voigt）・エネルギー分解能 E/ΔE の評価・トレンド表示を行う Windows 用アプリです。
このリポジトリは**実行ファイルの配布専用**です（ソースコードは含みません）。

## ダウンロード

Releases から `EnergyScanAnalyzer-<版>-win64.zip` をダウンロードしてください。
`SHA256.txt` はファイルが壊れていないかの確認用です。

## 動作環境

- Windows 10 / 11（64 ビット）
- インストール不要。Python や追加ライブラリ、インターネット接続も不要です。

## 使い方（はじめて起動するとき）

1. ダウンロードした zip を右クリック →「プロパティ」→「許可する」にチェックを入れてから展開します（警告が出にくくなります）。
2. 展開してできた `EnergyScanAnalyzer` フォルダを、**フォルダごと**任意の場所（例：`C:\Tools\EnergyScanAnalyzer`）に置きます。
   中の `_internal` フォルダは削除・移動しないでください（EXE だけを取り出すと起動しません）。
3. `EnergyScanAnalyzer.exe` をダブルクリックで起動します。署名のない実行ファイルのため、初回は
   「Windows によって PC が保護されました」と表示されることがあります。「詳細情報」→「実行」を選んでください。

操作方法は、アプリの「ヘルプ」→「マニュアル」（F1 キー）で開くマニュアルにまとめています。
概要は [使い方.txt](使い方.txt) にもあります。

ハッシュ値の確認（任意）：PowerShell で次を実行し、`SHA256.txt` の値と一致することを確かめます。

```
Get-FileHash .\EnergyScanAnalyzer-<版>-win64.zip -Algorithm SHA256
```

## 注意

- 元のデータファイルは変更しません（読み取り専用で開き、元データへの上書き保存は拒否します）。
- 設定ファイル・レジストリ・PATH・既存の Python は変更しません。
